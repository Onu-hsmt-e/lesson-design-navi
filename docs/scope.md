# 切り出し版の範囲(scope)

授業デザインナビ(設計書 2026-11-04 版)のうち、このリポジトリで作る範囲です。節番号は設計書のものです。

## 作るもの(必須)

- 授業資産のテキスト貼り付け。単元の入力は任意(3.2)
- 学校レベル3種(進学校 / 中堅校 / 基礎定着重視校)と、3観点ごとの1段調整。上端・下端は動かさない(3.2・11.2)
- 授業時間(既定50分)、活動の進め方(ペア・練り上げ・1回の上限、その他の自由入力)(3.2)
- 教室環境プロファイルの最小版: 授業の形、用紙と向き、氏名欄、解答欄の高さ(4・9.2)
- 設計の出力: 活動の一覧、仕分けと理由、改善提案(3観点・重点観点)、解答欄の区分、優先度、要確認一覧、読み取った単元・ねらい(推定)(3.3)
- 仕分けの判断順序、時間の見積り、出力前の自動チェック(2・5・6.1)
- 確定データ(スナップショット)(3.1)
- 検算と「要確認」(3.7)
- 制作: 生徒用プリント(用紙A4/B4/A3、向き、氏名欄、通し番号、優先度の印、聞き手メモ欄、ふり返り欄)と、教師用の時間配分表(3.3・3.4・3.9・6.2)
- 「AIの下書きです」の表示と、配布前チェック(3.3)
- 利用条件ページ(検算は保証ではない、など)(9.5)

## 余力があれば作るもの

- ペア・班の活動の進め方の表(3.3)
- 授業の形「板書・ノート中心」と板書計画(3.2・3.3)
- 確定データの書き出し・読み込み

## 作らないもの(意図的に外した)

- 画像・PDFの取り込み(OCR)、単元・着眼点ナビとの統合・検索
- 教科書の表示モードと、教材の種別
- 解説つき全文解答、要点スライド、教師用の指導案本体(発問・想定反応)、評価規準・評価教材
- 年間計画・進度(公開後の任意タスク)、実施ログ、実績での補正
- 生徒の入力画面、決済、共有、学校導入の説明資料

## 範囲を決める原則

- 1本の流れ(入力 → 仕分け → 確認・修正 → 確定 → 印刷)を、最後まで動かすことを優先する。
- 判断ロジックと時間の計算は、サーバー側のコードで行う。AIは特徴の抽出と、文章の生成だけを担当する。
- 遅れたときに削る順: 余力 → 印刷の見た目 → AIの理由文と単元の推定 → 検算の例外処理。
- 削らないもの: 段階1〜4(土台・DB・画面・ルールエンジン)、テスト、CI、保存期限と削除、利用条件ページ。

## 公開しないもの

設計書の全文、料金、事業計画、製品版の差別化部分は、このリポジトリに置きません。
